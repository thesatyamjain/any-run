# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within AnyRun, please report it privately:

1. Do **not** open a public GitHub issue.
2. Email the maintainer or use GitHub Security Advisories to submit a private report.
3. Include detailed steps to reproduce the issue, along with environment details (Node version, OS).

We appreciate responsible disclosure and aim to acknowledge and address reported vulnerabilities promptly.
